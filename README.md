# Ranjith Kumar D — Personal Portfolio

Personal portfolio website for **Ranjith Kumar D**, Senior Data Engineer → AI Engineer at Oracle Life Sciences.

**Status:** Private while in development. The live design/build is maintained as a Muse Space ("Personal Website"); this repository holds the publishable source for GitHub Pages.

## Purpose

Recruiter- and hiring-manager-facing portfolio for Senior Data Engineer, AI Engineer, and Forward Deployed Engineer roles.

## Sections

- Home — hero, rotating role titles, identity keywords, headline stats
- About — story and operating principles
- Experience — Oracle, Capital One, UCM VR, HDFC AMC, Karvy
- Skills — filterable skill map
- Projects — selected data and AI engineering work
- Blog — "What AI Changed" series (Post #1: the TESS planet, published Nov 8, 2026)
- Résumé — downloadable master résumé and certifications
- Contact — LinkedIn, GitHub, email

## Design

Futuristic cyborg visual pattern blended with Japanese dedication and discipline:
Kaizen (continuous improvement), Shūren (rigorous training), Shokunin (craftsmanship), Teinei (care and polish).

Design reference: [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills) (MIT), cloned locally for reference during the build.
