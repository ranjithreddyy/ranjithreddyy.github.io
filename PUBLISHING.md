# Publishing to GitHub Pages

1. Export the final build of the Muse Space "Personal Website" as a single HTML file and save it here as `index.html` (replacing the starter scaffold).
2. Add the master résumé PDF as `resume.pdf` if the download should be served from Pages directly.
3. Push to `main`.
4. In GitHub: make the repository public (Settings → General → Danger Zone → Change visibility). GitHub Pages on the free plan does not publish from private repositories.
5. Enable Pages: Settings → Pages → Deploy from a branch → `main` / root.
6. Site goes live at https://ranjithreddyy.github.io/ranjith-kumar-portfolio/ — or rename the repo to `ranjithreddyy.github.io` at publish time for the root URL (note: an old 2024 repo currently holds that name and would need to be renamed/archived first, with its contents preserved).

Until step 4, nothing in this repo is public.
